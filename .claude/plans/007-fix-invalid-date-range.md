# 007: 終了日が開始日より前のデータで ICS 生成が失敗する問題の修正

## 背景

GitHub Actions (run 40096122675) で `generate_ics` が `ValueError: End must be after begin` で失敗。

原因は `hakubutsu_fes` スクレイパー。サイトに今回 (2026年 12月5日(土) 6日(日)) と前回 (2026年 7月19日(日) 20日(月・祝)) の
2 回分の開催情報が載っており、`_parse_dates` がページ内の最初と最後の日付を開始日・終了日にしていたため
`start=2026-12-05, end=2026-07-19` となった。会場も前回分 (東京ビッグサイト) を拾っていた。

---

## 開発プラン

- [x] `hakubutsu_fes._parse_dates`: 最初の開催日とそれに続く日 (`6日(日)`, `〜2026年8月2日` 等) のみで期間を決める
- [x] `hakubutsu_fes`: 会場を日付に続く「〜にて開催/で開催」の文から取得し、なければ従来ロジック
- [x] `main`: 終了日 < 開始日のデータを警告ログ付きで除外し、1 件の不正データでデプロイ全体が落ちないようにする
- [x] テスト追加 (複数回開催ページ、不正期間の除外)
- [x] lint・テスト・`uv run python -m scripts.main` で動作確認
